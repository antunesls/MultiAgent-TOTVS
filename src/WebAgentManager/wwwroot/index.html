Configurações

Preferências e dados exclusivos do seu usuário do Windows.

Navegador padrão

Deixe vazio para usar o padrão do Windows (WebAgent 1.0.24 ou superior). Cada ambiente pode ter um navegador diferente.

Backup dos cadastros

Exporte ambientes e preferências em JSON. A importação mescla os cadastros e exige que os agentes vinculados já existam nesta instalação.

O JSON não inclui executáveis, DLLs ou histórico. Para backup completo, feche o gerenciador e copie toda a pasta de dados.

Diagnóstico local

Nenhuma alteração no AppServer.ini é feita. Certificados e permissões de acesso à rede local devem ser confirmados por você no Windows/navegador. Perfis, cookies e credenciais do navegador não são isolados pelo gerenciador.

Iniciar junto com o Windows

Após publicar, execute scripts/Instalar-InicioUsuario.ps1 para criar um atalho somente no seu login. A inicialização automática não é ativada sem sua ação.

Para remover, execute o mesmo script com -Remover. Consulte o README do projeto para publicação e operação.

Preparar WebAgent

Importe o instalador oficial ou uma pasta já instalada.

Máximo 512 MB. A assinatura digital deve ser válida e pertencer à TOTVS. O gerenciador não extrai pacotes nem instala silenciosamente.

  1. Selecione e verifique o instalador.
  2. Na biblioteca, confirme a abertura do instalador. Todos os WebAgents precisam estar fechados.
  3. Conclua no Windows e feche o agente pela bandeja.
  4. Clique em “Capturar instalação” para preservar a versão.

Informe uma pasta local já instalada. Feche os agentes antes de copiar. A origem será preservada; links simbólicos e junctions não são aceitos.
